# Exp4-01 二进制整数转十进制

实验 4 第 1 题。

## 题目

从键盘输入一个二进制整数（不超过 10 位），把它转换成十进制整数并输出。要求使用 `while` 语句。

## 语言

C++（`src/binary_to_decimal.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/binary_to_decimal.cpp -o builds/binary_to_decimal
./builds/binary_to_decimal
```

## 运行示例

输入 `1001001`：

```
请输入一个二进制整数:1001001
转换成十进制是:73
```

## 要点

- 输入是「二进制串」却用 `cin >> num1` 读进一个整数，所以对这个数取 `% 10` 拿到的正好是**最右边那一位**，`/ 10` 就是把这位于「删掉」。这套「取余得最低位、整除去掉最低位」的手法，处理十进制数字和二进制串是一样的。
- 权值 `base` 从 1 开始，每处理完一位就乘 2：1、2、4、8……第 i 位（从右往左数，从 0 起）的权值正好是 2^i。
- 变量用 `long long` 而不是 `int`。`int` 上限是 2147483647，只能容纳 10 位以内的输入；换成 `long long` 后 19 位以内都安全。超过 19 位就得改成按字符串逐位处理了。
- `num1 > 0` 作为循环条件：输入 0 时循环一次都不进，直接输出 0，结果正确。
- 这个算法不会检查输入里有没有 0/1 以外的数字，输入 `1234` 也会「算」出 26。要严格校验就得逐位判断。

## 另一个办法

不用取余，直接按字符串读、从高位往低位推（霍纳法则）：

```cpp
string s;
cin >> s;
long long sum = 0;
for (int i = 0; i < s.size(); i++)
    sum = sum * 2 + (s[i] - '0');
```

这种写法没有长度上限，但要多 `#include<string>`。
