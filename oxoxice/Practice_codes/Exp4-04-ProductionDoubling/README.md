# Exp4-04 产值翻一番需要多少年

实验 4 第 4 题。

## 题目

某工厂今年产值 100 万元，每年增长率相同。从键盘输入增长率，计算多少年后产值翻一番（达到原来的 2 倍），并输出每一年的产值。

## 语言

C++（`src/production_doubling.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/production_doubling.cpp -o builds/production_doubling
./builds/production_doubling
```

## 运行示例

输入 `0.13`：

```
请输入年增长率:0.13
1年后产值为：113
2年后产值为：127.69
3年后产值为：144.29
4年后产值为：163.047
5年后产值为：184.244
6年后产值为：208.195
需要6年
```

## 要点

- 循环条件是「只要还没到 200 就继续」，所以写 `all < 200`。如果心里想的是「产值超过 200 就结束」而直接写 `all >= 200`，一开始 100 就满足，循环一次都不会进。
- 增长是复利：`all = all * (1 + rate)`，不是每年加固定的 `100 * rate`。
- 输出走默认格式（6 位有效数字），所以 127.69 显示完整，163.047 只留 3 位小数。要固定 2 位小数得加 `cout << fixed << setprecision(2)`。
- 增长率必须大于 0，否则产值永远不变，`all < 200` 永远成立，就是死循环。所以前面加了一道 `if (rate <= 0)` 拦截。
- 这道题不需要 `long long`，也不用担心溢出，但要小心浮点累乘的累积误差。
