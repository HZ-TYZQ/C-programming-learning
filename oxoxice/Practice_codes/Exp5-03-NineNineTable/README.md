# 实验 5 第 3 题：九九乘法表

## 题目

编程输出九九乘法表，格式参见样张。

## 输出样例

```
                                                1*1=1
                                        1*2=2   2*2=4
                                1*3=3   2*3=6   3*3=9
                        1*4=4   2*4=8   3*4=12  4*4=16
                ...
1*9=9   2*9=18  3*9=27  4*9=36  5*9=45  6*9=54  7*9=63  8*9=72  9*9=81
```

特点：**右对齐**，第 i 行有 i 个算式，最后一行顶到最左边。

## 思路

1. 外层 `i` 从 1 到 9
2. 每行先补 `9 - i` 组空格，每组 **8 个空格**——正好是一个算式的宽度
3. 内层 `j` 从 1 到 `i`，输出 `j*i=结果`
4. 每个算式补到 **8 个字符宽**：结果是一位数时算式共 5 个字符，补 3 个空格；结果是两位数时算式共 6 个字符，补 2 个空格

## 为什么不能用 setw

```cpp
cout << j << "*" << i << "=" << setw(4) << i * j << " ";
```

这种写法只能让**乘积**对齐，但整个算式的宽度不固定（`1*1=` 和 `2*9=` 一样长，后面的数字却长短不一），结果就是每列宽窄不一，整张表也做不到右对齐。

要让整行右边缘对齐，必须**把每个算式补到同一个总宽度（8）**，所以补空格的数量要自己算。

## 易错点

| 坑 | 后果 |
| --- | --- |
| 行首不补空格 | 输出的是左下三角，和样张上下颠倒 |
| 用 `setw` 补乘积 | 列宽忽宽忽窄，右边对不齐 |
| 空格补 7 个而不是 8 个 | 每行会往左错开一列，越往下越歪 |
