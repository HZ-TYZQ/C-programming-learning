# Exp3-03 阶梯气费计算

实验 3 第 3 题。

## 题目

从键盘输入居民一年的天然气使用量，按阶梯气费标准计算全年气费总价。某市的阶梯气费标准为：

| 阶梯 | 年用气量 | 单价 |
| --- | --- | --- |
| 第一阶梯 | 0—360（含）立方米 | 2.02 元/立方米 |
| 第二阶梯 | 360—600（含）立方米的部分 | 2.43 元/立方米 |
| 第三阶梯 | 600 立方米以上的部分 | 3.04 元/立方米 |

要求使用 `if-else` 嵌套语句实现多路分支结构，输出结果保留 1 位小数。

## 语言

C++（`src/gas_tier.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/gas_tier.cpp -o builds/gas_tier
./builds/gas_tier
```

```

输入 `400`：

```

数据输入错误！

## 要点

- 关键是题目里「的部分」三个字：360—600 立方米**的部分**按 2.43 元，意思是只有超出 360 的那部分才涨价，前面的 360 立方米仍按 2.02 元算。所以这是**分段累加**，不是总量乘一个单价。
- 三档的算式：
  - `v <= 360`：`cost = v * 2.02`
  - `v <= 600`：`cost = 360 * 2.02 + (v - 360) * 2.43`
  - 其他：`cost = 360 * 2.02 + 240 * 2.43 + (v - 600) * 3.04`
- 其中 `360 * 2.02 = 727.2` 和 `240 * 2.43 = 583.2` 是固定不变的「地基」，只有最上面一段跟着输入变化。
- 保留 1 位小数要用 `fixed << setprecision(1)`。`fixed` 表示按小数点后固定位数；只写 `setprecision(1)` 的话含义是「总共 1 位有效数字」，607.111 会被输出成 `6e+02`。
- 输入负数时直接输出「数据输入错误！」并 `return 0`。如果不提前结束，后面会拿没算过的 `cost` 去打印总价。
- 边界按「（含）」处理：`v <= 360` 把 360 归第一档，`v <= 600` 把 600 归第二档。
