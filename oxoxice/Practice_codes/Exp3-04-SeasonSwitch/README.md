# Exp3-04 判断月份所属季节（switch）

实验 3 第 4 题。

## 题目

从键盘输入月份，判断该月是什么季节：3~5 月为春季，6~8 月为夏季，9~11 月为秋季，12、1、2 月为冬季。

要求：判断季节前，先使用 `if-else` 语句判断输入月份的合法性，然后使用 `switch` 语句判断季节，且 `switch` 中的 `case` 分句尽量少。

## 语言

C++（`src/season_switch.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/season_switch.cpp -o builds/season_switch
./builds/season_switch
```

## 运行示例

输入 `4`：

```
请输入月份：4
4月处于春季
```

输入 `7`：

```
请输入月份：7
7月处于夏季
```

输入 `10`：

```
请输入月份：10
10月处于秋季
```

输入 `-2`：

```
请输入月份：-2
月份输入错误
```

## 要点

- 合法性判断放在 `switch` 外面。月份可能是 `-2` 或 `13`，这些值如果直接进 `switch`，会掉进 `default`（或者一个分支都不匹配），输出「-2月处于冬季」这种荒谬结果。所以先用 `if` 拦在门外。
- `switch` 的四条规则：括号里只能是整型（`int`、`char`，不能是 `double`）；`case` 后面只能是常量，不能写范围；没有 `break` 会继续往下穿透；`default` 兜底所有没被接住的值。
- 减少分句靠 **case 穿透**：把几个 `case` 摞在一起，中间不写语句也不写 `break`，最后共用一个 `break`。这样 12 个月只有 4 个分句。
- 冬季是 12、1、2，在数轴上不连续，所以单独列三个 `case`；用 `default` 接住也可以，但显式列出来更好读。
- 漏写 `break` 的话，击中 `case 3` 会一路穿到夏季、秋季、冬季，把四个季节全打印一遍。
- 输入语句是 `cin >> m;`，冒号 `:` 和分号 `;` 不能写混。
