# Exp2-03 判断英文字母

实验 2 第 3 题。

## 题目

输入一个字符，使用双分支结构（`if...else`）判断其是否为英文字母。

## 语言

C++（`src/letter_check.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/letter_check.cpp -o builds/letter_check
./builds/letter_check
```

## 运行示例

```
请输入任意一个字母：F
输入的字符F是英文字母
```

```
请输入任意一个字母：#
输入的字符#不是英文字母
```

## 要点

- 存「字符」必须用 `char`。用 `int` 接 `cin` 时，输入字母会读取失败，C++11 起变量被置为 `0`。
- 英文字母是**两段**范围：`A~Z` 和 `a~z`。段内用 `&&`（同时满足上下界），段间用 `||`（满足任一段即可）。
- 边界用 `>=` 和 `<=`，否则 `A`、`Z`、`a`、`z` 四个字母本身会被漏掉。
- 常见错误：写成 `'A' <= ch <= 'Z'`。C++ 会先算 `('A' <= ch)` 得到 0 或 1，再和 `'Z'` 比较，结果**永远为真**。
