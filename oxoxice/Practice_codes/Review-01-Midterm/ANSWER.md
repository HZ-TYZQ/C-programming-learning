## A 部分：快速判断

### A1. `int a = 5 / 2;` 后 a 的值是 2.5

**答案：错** ｜ 作答：✔

`5 / 2` 是**整数除以整数**，结果还是整数，小数部分直接**截断**（不是四舍五入），所以是 2。要把 `a` 声明成 `double`，并且写成 `5 / 2.0` 才能得到 2.5。

注意区分：

```cpp
5 / 2      // 2      两个都是 int
5 / 2.0    // 2.5    有 double 参与，结果是 double
5.0 / 2    // 2.5
```

### A2. `if (a = 0)` 是在判断 a 是否等于 0

**答案：错** ｜ 作答：✔

`=` 是赋值。`a = 0` 先把 0 赋给 a，整个表达式的值就是 0，被当作「假」，所以 `if` 里的语句**永远不执行**，而且 a 被悄悄改成了 0。

判断相等必须用 `==`。

> 这个坑编译器一般只给警告，不给错误，所以特别容易漏。

### A3. 在函数里修改形参，会改变调用处的实参

**答案：错** ｜ 作答：✔

**值传递 = 复印**。函数拿到的是一份副本，改副本不影响原件。想让函数改动外面的变量，需要用引用（`int &a`）或指针，那是后面的内容。

### A4. `do { ... } while (false);` 的循环体一次都不执行

**答案：错** ｜ 作答：✔

`do-while` 是**先执行、后判断**，所以至少执行一次。这也是它和 `while` 唯一但关键的区别。

### A5. `for` 中间那段是「结束条件」

**答案：错** ｜ 作答：✔

中间那段是**继续条件**：条件成立就再转一圈，不成立才退出。

```cpp
for (int i = 0; i < 5; i++)
```

读作：「只要 `i < 5` 就继续」。`i` 变成 5 的时候条件不成立，循环结束。

### A6. 一个 int 函数只要有一条路径写了 return 就行

**答案：错** ｜ 作答：✔（理由写「不知道」，需要补）

**每一条执行路径都要有 `return`。** 少一条，走到那条路径时函数会返回一个**不确定的值**（内存里残留的垃圾），而且不报错——最难查的一类 bug。

```cpp
int maxOf(int a, int b)
{
    if (a > b) return a;
    if (b > a) return b;
}                    // a == b 时从这里掉出去，返回值不确定
```

补法见 C2。

### A7. 递归里写在调用之前的语句，执行顺序由外往内

**答案：对** ｜ 作答：✔

这条已经用 `cout` 位置验证过了：

- 写在递归调用**之前** → 由外往内（5 4 3 2 1 0）
- 写在递归调用**之后** → 由内往外（0 1 2 3 4 5）

### A8. `for (int i = 0; i < 5; i++);` 的 i++ 会执行 5 次

**答案：对** ｜ 作答：✘（答「6 次」）

完整走一遍：

| 第几次判断 | i 的值 | `i < 5` | 执行什么 |
| --- | --- | --- | --- |
| 1 | 0 | 真 | 空语句 → `i++` → i=1 |
| 2 | 1 | 真 | 空语句 → `i++` → i=2 |
| 3 | 2 | 真 | 空语句 → `i++` → i=3 |
| 4 | 3 | 真 | 空语句 → `i++` → i=4 |
| 5 | 4 | 真 | 空语句 → `i++` → i=5 |
| 6 | 5 | **假** | **直接退出，不再执行 i++** |

所以循环体（空语句）执行 **5** 次，`i++` 也执行 **5** 次。

**关键点**：条件不成立的那一次，只做判断，不做循环体，也不做 `i++`。不要把它数进去。

## B 部分：读代码写输出

### B1. 答案 `34` ｜ 作答：✔

`i` 取 1, 4, 7, ..., 100。个数 = `(100 - 1) / 3 + 1` = `33 + 1` = **34**。

`i += 3` 就是 `i = i + 3`。

### B2. 答案 `3 1 3.5` ｜ 作答：`3 1 3`（部分对）

三个空分别：

| 表达式 | 结果 | 原因 |
| --- | --- | --- |
| `a / b` 即 `7 / 2` | `3` | 整数除法，截断 |
| `a % b` 即 `7 % 2` | `1` | 余数 |
| `a / 2.0` | `3.5` | `2.0` 是 double，结果自动变成 double |

**第二个空你写 3，说明只注意到前面全是整数运算。** 只要有一个操作数是浮点数，整个表达式就按浮点数算——这条要记住，以后算平均数、百分比全靠它。

### B3. 答案 `5` ｜ 作答：✔

值传递，函数里改的是副本。

### B4. 答案 `01210` ｜ 作答：`0 1 2 3`

```cpp
int x = 10;              // 外层 x
for (int i = 0; i < 3; i++)
{
    int x = i;           // ← 内层 x，遮蔽了外层
    cout << x;           // 打印内层：0 1 2
}
cout << x;               // 循环结束，内层 x 已失效，打印外层：10
```

输出连起来是 `0` `1` `2` `10` → **`01210`**。

两个要点：

1. 循环体里的 `int x = i;` 是**另一个变量**，作用域只有那一对大括号之内
2. 内层失效后，外层的 `x` 从来没被改过，还是 10

> 同名变量可以共存，里层「盖住」外层，这叫**遮蔽（shadowing）**。虽然合法，但实际写代码时应尽量避免——太容易看错。

### B5. 答案 `7 5 7` ｜ 作答：`5 5 6`

逐个算：

```cpp
int a = 5;
int b = a++;    // 后置 ++：先把旧值给 b，再让 a 加 1
                // → b = 5，a = 6

int c = ++a;    // 前置 ++：先让 a 加 1，再把新值给 c
                // → a = 7，c = 7

cout << a << " " << b << " " << c;   // 7 5 7
```

口诀：

| 写法 | 含义 | 记忆 |
| --- | --- | --- |
| `a++` | 先用后加 | `++` 在后面，所以「后面才加」 |
| `++a` | 先加后用 | `++` 在前面，所以「先加」 |

> 如果 `i++` / `++i` 单独成一条语句（`i++;`），两者完全一样。只有**参与别的运算**（赋值、打印、传参）时才有区别。

### B6. 答案 `15` ｜ 作答：✔

注意这里是 `f(n - 2)`，不是 `f(n - 1)`：

```
f(5) = 5 * f(3)
f(3) = 3 * f(1)
f(1) = 1          ← 撞到终止条件 n <= 1
f(3) = 3 * 1 = 3
f(5) = 5 * 3 = 15
```

这个函数算的其实是「5 × 3 × 1」，也就是奇数阶乘。

## C 部分：找错并改正

### C1. 答案

```cpp
for (int i = 1; i <= 10; i++)
{
    cout << i;
}
```

原代码两处错：

1. `for` 的三段之间用了**逗号**，必须是**分号**
2. `for` 后面跟的是 `{`，必须是**圆括号** `(`

**作答的问题**：改对了结构，但用的是**全角分号 `；`**。全角符号在 C++ 里是无效字符，编译器会报一堆语法错误。

> 代码里所有标点都必须是**半角**（英文输入法）：`;` `,` `(` `)` `{` `}` `"` `'`。
> 判断方法：切到英文输入法再敲，或者看符号的宽度——全角符号明显更宽。

### C2. 答案

```cpp
int maxOf(int a, int b)
{
    if (a > b) return a;
    return b;              // a <= b 时返回 b，顺带覆盖了 a == b
}
```

或者：

```cpp
int maxOf(int a, int b)
{
    if (a > b) return a;
    else       return b;
}
```

原代码的问题：`a == b` 时两条 `if` 都不成立，函数**没有 return 就掉出去了**。

**作答的问题比较多**，逐个说：

| 问题 | 说明 |
| --- | --- |
| 加了 `if (a == b)` 判「输入有误」 | **a == b 是合法输入**。两个数一样大，最大值就是它俩，没什么可报错的 |
| `if (a=b)` 用了赋值 | 判断相等要 `==`，这里会改写 a 的值 |
| 大括号位置错乱 | `int maxOf(int a, int b)` 后面直接跟 `if`，函数体没开 |
| 字符串末尾缺 `;` | `cout << "..."` 后面必须加分号 |
| **仍然没解决原问题** | 就算加了那个 if，a == b 时依然没有 return |

这道题的原题是「**漏了一种情况**」，正确做法是**补上那种情况的返回值**（`return b;`），而不是**把它当成错误输入去报错**。

> 值得记的一点：**判定「输入有误」只在数据真的不合法时才做**。两个数相等不是错误。

### C3. 答案

```cpp
int add(int a, int b)      // ① 每个参数都要写类型
{
    return a + b;
}

int main()
{
    cout << add(3, 4);     // ② 调用时不写类型
    return 0;
}
```

原代码两处错：

1. **定义**时 `int a, b` 里 `b` 没有类型 → 应为 `int a, int b`
2. **调用**时写成了 `add(int 3, int 4)` → 应为 `add(3, 4)`

**作答只改了 ②，① 没改。** 记住：

> **定义（声明）时要写类型，调用时只写值。**

```cpp
int add(int a, int b);     // 声明：写类型
add(3, 4);                 // 调用：不写类型
```

## D 部分：编程题

### D1. 参考代码 ｜ 作答：✔ 满分

```cpp
#include <iostream>
using namespace std;

int sumTo(int n)
{
    int sum = 0;

    {
        sum = sum + i;
    }
    return sum;
}

int main()
{
    int n;
    cin >> n;
    cout << sumTo(n) << endl;
    return 0;
}
```

你的代码和这个逻辑一致，完全正确。（`sumTo(100)` = 5050 ✓）

### D2. 参考代码 ｜ 作答：✘ 3/10

```cpp
#include <iostream>
using namespace std;

// 水仙花数：三位数，各位数字的立方和等于它本身
bool isNarcissistic(int n)
{
    int a = n / 100;          // 百位
    int b = n / 10 % 10;      // 十位
    int c = n % 10;           // 个位

    return n == a * a * a + b * b * b + c * c * c;
}

int main()
{
    for (int n = 100; n <= 999; n++)
    {
        if (isNarcissistic(n)) cout << n << endl;
    }
    return 0;
}
```

输出：

```
153
370
371
407
```

**作答的三处问题：**

#### ① 十位取错了

```cpp
int b = n / 10;        // ✘ 以 153 为例，得到 15，不是 5
int b = n / 10 % 10;   // ✔ 先去掉个位得 15，再取末位得 5
```

拆位公式（三位数 n）：

| 位 | 写法 | 153 的结果 |
| --- | --- | --- |
| 百位 | `n / 100` | 1 |
| 十位 | `n / 10 % 10` | 5 |
| 个位 | `n % 10` | 3 |

记法：**「除到这一位，再取末位」**。

#### ② `if (n = ...)` 又把 `==` 写成了 `=`

```cpp
if (n = a * a * a + b * b * b + c * c * c)   // ✘
```

这不只是「少判断一次」，后果更严重：它把立方和**赋给了 n**，表达式的值就是那个和。只有在和为 0 时才为假，所以函数几乎**永远返回 true**。

正确写法：

```cpp
if (n == a * a * a + b * b * b + c * c * c) return true;
return false;
```

更简洁的一行版（`n == ...` 本身就是 `bool`）：

```cpp
return n == a * a * a + b * b * b + c * c * c;
```

#### ③ 题目要求输出 100~999 全部，不是让用户输一个

题目写的是「在 `main` 里输出 100~999 之间**所有**的水仙花数」。你的 `main` 是读一个数判断一个，只完成了一半。

> 读题时注意这两类要求完全不同：
> - 「判断输入的数是不是」 → `cin` 一个，判断一个
> - 「输出某区间内所有的」 → 用 `for` 扫一遍区间

### D3. 参考代码 ｜ 作答：✔ 9/10

```cpp
#include <iostream>
using namespace std;

long long fact(int n)
{
    if (n <= 1) return 1;                        // 0! = 1! = 1
    return (long long)n * fact(n - 1);           // 先转 long long 再乘，防溢出
}

int main()
{
    long long sum = 0;
    for (int i = 1; i <= 10; i++)
    {
        sum = sum + fact(i);
    }
    cout << sum << endl;      // 4037913
    return 0;
}
```

你的实现基本一致，`(long long)n * fact(n - 1)` 这句转型写得很好——**在乘法之前就转**，而不是等结果溢出了再转，这点很多人会写错。

小扣分点：题目要求「输出 1!+2!+...+10!」，写成了读入 n 再累加到 n。功能更通用了，但和题目要求不完全一致。

**关于 `long long` 的必要性：**

```
10! = 3,628,800           int 装得下
12! = 479,001,600         int 装得下
13! = 6,227,020,800       ✘ 超过 int 上限 2,147,483,647
```

阶乘增长极快，写阶乘函数一律用 `long long`。

## 需要优先补的 7 个点

按重要程度排：

### 1. `i++` 和 `++i` 的区别（B5 丢 3 分）

```cpp
b = a++;   // 先用后加
c = ++a;   // 先加后用
```

单独成句时无区别，参与运算时必须分清。

### 2. 变量的作用域与遮蔽（B4 丢 3 分）

同一名字的内层变量会「盖住」外层变量，内层失效后外层原值不变。**循环里定义的变量出了循环就失效**。

### 3. 循环执行几次的边界（A8 丢 2 分）

条件不成立的那一次，**只判断，不执行循环体，也不执行 `i++`**。数不清就画表走一遍。

### 4. 整数除法 vs 浮点除法（B2 部分丢分）

`7 / 2` 是 3，`7 / 2.0` 是 3.5。只要有一个操作数是浮点数，结果就是浮点数。

### 5. 每条路径都要有 return（C2）

非 `void` 函数如果存在没有 `return` 的路径，会返回垃圾值。写完检查一遍：「有没有哪种输入，会让函数走到最后却没 return？」

### 6. 拆位公式（D2）

```
百位 n / 100      十位 n / 10 % 10      个位 n % 10
```

### 7. 代码里的符号必须是半角（C1）

`;` 不是 `；`，`,` 不是 `，`，`(` 不是 `（`。全角符号会导致一堆莫名其妙的语法错误。
