# 期中复习卷（第一套）

**范围**：顺序结构 / 选择结构 / 循环结构 / 函数 / 递归

**建议时间**：判断题 + 读代码 + 找错 25 分钟，编程题 40 分钟

做题规则：

- 先全部做完再对答案，不要边做边看，这样才看得出哪里真的不熟
- 判断题除了写「对 / 错」，还要用**一句话**写理由
- 编程题不用加注释，能跑对就行

---

## A 部分：快速判断（8 题，每题 2 分）

判断对错，并写一句理由。

**A1.** `int a = 5 / 2;` 执行后 `a` 的值是 `2.5`。

**A2.** `if (a = 0)` 是在判断 `a` 是否等于 0。

**A3.** 在函数里修改形参的值，会同时改变调用处实参的值。

**A4.** `do { ... } while (false);` 里的循环体一次都不会执行。

**A5.** `for` 循环中间那一段是「**结束**条件」，条件成立时就退出循环。

**A6.** 一个 `int` 函数只要有一条路径写了 `return`，其他路径可以不管。

**A7.** 递归函数里写在递归调用**之前**的语句，执行顺序是从外层往内层。

**A8.** `for (int i = 0; i < 5; i++);` 这行的循环体是空语句，`i++` 会执行 5 次。

不要运行，人脑算。写出完整输出。

**B1.**

```cpp

for (int i = 1; i <= 100; i += 3) s++;
cout << s;
```

**B2.**


**B3.**

```cpp

int main() { int n = 5; f(n); cout << n; return 0; }
```

**B4.**

```cpp
int x = 10;
for (int i = 0; i < 3; i++)
{
    int x = i;
    cout << x;
}
cout << x;
```

**B5.**

```cpp

int b = a++;
int c = ++a;
cout << a << " " << b << " " << c;
```

**B6.**

```cpp
int f(int n)
{
    if (n <= 1) return 1;
    return n * f(n - 2);
}
int main() { cout << f(5); return 0; }
```

## D 部分：编程题

**D1.（8 分）**

写一个函数 `int sumTo(int n)`，返回 `1 + 2 + ... + n`（用循环）。
`main` 里输入 n，输出结果。

```
输入：100
输出：5050
```

**D2.（10 分）**

写一个函数 `bool isNarcissistic(int n)`，判断 n 是否是**水仙花数**。

> 水仙花数：三位数，且**各位数字的立方和 = 它本身**。
> 例如 153 → 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 ✓

然后在 `main` 里输出 **100~999** 之间所有的水仙花数。

（提示：用 `n % 10` 取个位，`n / 10` 去掉个位，循环三次）

**D3.（10 分）**

先用**递归**写 `long long fact(int n)` 求 n 的阶乘（0! = 1）。
然后输出 `1! + 2! + 3! + ... + 10!` 的和。

```
期望输出：4037913
```

（提示：主函数里用一个循环，每次调用 `fact(i)` 累加。注意返回类型用 `long long`——10! = 3628800，11! 就超 `int` 了。）
