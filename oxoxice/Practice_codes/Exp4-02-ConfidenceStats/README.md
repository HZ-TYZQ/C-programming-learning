# Exp4-02 AI 推理置信度统计

实验 4 第 2 题。

## 题目

从键盘输入一系列置信度数值（0～100），输入小于 0 或大于 100 的数就立即结束输入。计算所有有效置信度的平均值（保留 1 位小数），并统计置信度 ≥60 的次数。要求使用 `do-while` 语句。

## 语言

C++（`src/confidence_stats.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/confidence_stats.cpp -o builds/confidence_stats
./builds/confidence_stats
```

## 运行示例

输入 `81.3 64 79 54.2 92.4 43 83.5 -1`：

```
请依次输入AI推理置信度，输入小于0或大于100的数结束程序：
81.3 64 79 54.2 92.4 43 83.5 -1
7次推理的平均置信度：71.1
达标的推理次数：5
```

## 要点

- 置信度是**小数**（81.3、54.2），变量必须是 `double`。如果用 `int`，读 81.3 只会拿到 81，剩下的小数点留在输入缓冲区里，下一次读入直接失败，后面全乱。
- `cin >>` 会跳过空格和换行，所以一行敲完、分好几行敲，效果完全一样，都是「空格分隔的一串数」。
- `do-while` 是**先执行再判断**，进来第一件事一定是 `cin >> num1`，所以不需要在循环前面再读一次。条件写的是「继续的条件」：`num1 >= 0 && num1 <= 100`，一旦读到越界值就不再继续。
- 统计只统计 0～100 之间的值，所以循环体里还要再判断一次。那次越界的输入既不计入次数，也不计入和。
- 平均值要用浮点除法。`sum` 已经是 `double`，所以 `sum / round1` 天然是小数除法；如果两个都是 `int`，就必须写 `(double)sum / round1`。
- 必须先判断 `round1 == 0` 再做除法，否则用户一上来就输入 `-1`，整数除以 0 会让程序直接崩溃。
