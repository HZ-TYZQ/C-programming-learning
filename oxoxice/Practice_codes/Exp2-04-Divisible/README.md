# Exp2-04 整除判断

实验 2 第 4 题。

## 题目

输入一个整数，使用双分支结构判断其能否被 4 整除；再判断其是否不能被 7 整除（要求使用「不等于」运算符）。

## 语言

C++（`src/divisible.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/divisible.cpp -o builds/divisible
./builds/divisible
```

## 运行示例

```
请输入一个整数：28
28能被4整除
28能被7整除
```

```
请输入一个整数：21
21不能被4整除
21能被7整除
```

## 要点

- 「能被整除」= 余数为 0，用取余运算符 `%`，不是除法 `/`。
- 两个判断相互独立，各输出一行，所以是**两个并列的 `if...else`**，不是 `if...else if`。
- 第二问要求用「不等于」运算符 `!=`：`if (a % 7 != 0)` 成立时输出「不能被7整除」，输出方向和第二问的条件是相反的。
