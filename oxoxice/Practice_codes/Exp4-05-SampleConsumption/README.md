# Exp4-05 取完 AI 训练样本需要多少天

实验 4 第 5 题。

## 题目

数据集共 n 条样本，n 由键盘输入。每天取走当前剩余数量的一半（奇数取整数商），再额外多取 1 条。输出每天训练后剩余的样本数，以及取完全部样本所需的天数。

## 语言

C++（`src/sample_consumption.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/sample_consumption.cpp -o builds/sample_consumption
./builds/sample_consumption
```

## 运行示例

输入 `18`：

```
请输入AI训练样本总数n:18
第1天训练后剩余：8
第2天训练后剩余：3
第3天训练后剩余：1
第4天训练后剩余：0
将所有样本取用完毕共需4天
```

## 要点

- 每天剩多少：`sum - sum / 2 - 1`。`sum / 2` 是整数除法，奇数时自动向下取整（剩 9 条时 `9 / 2 = 4`），正好满足题目「一半取整数商」的要求。
- 循环条件 `sum > 0`：还有剩余就继续取。n 是 1 或 2 时，第一天就减到 0，只循环一次。
- 天数用**循环外的**变量累加。如果把 `int i` 写在 `for (int i = 1; ...)` 的括号里，出了循环这个名字就没了，最后那行统计时会报「未声明」。
- 天数在循环里加 1 后，循环结束时它是「多算了一次」的值。用 `while` + 独立计数器 `day` 就不会有这个问题；用 `for` 的话最后要输出 `i - 1`。
- 公式不会被减成负数：`sum = 1` 时 `1 - 0 - 1 = 0`，`sum = 2` 时 `2 - 1 - 1 = 0`，都停在 0。
