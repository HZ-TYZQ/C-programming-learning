# 实验 5 第 2 题：字符三角形

## 题目

从键盘输入行数和一个字符，输出由这个字符构成的图形。

## 输入输出样例

```
请输入行数和字符: 5 #
        #
      # #
    # # #
  # # #
# # # #
```

```
请输入行数和字符: 6 k
          k
        k k
      k k k
    k k k k
  k k k k k
k k k k k k
```

## 思路

双重循环：

- 外层 `i`：控制行号，共 `num1` 行
- 内层分两块：
  1. 先补空格，`num1 - i` 组，每组 **2 个空格**
  2. 再输出 `i` 个字符，每个用 `setw(2)` 占 **2 列**

因为每个字符占 2 列，所以空格也必须按「2 个一组」来补，图形才对得齐。

## 易错点

| 坑 | 后果 |
| --- | --- |
| 空格只补 1 个 | 字符占 2 列、空格占 1 列，图形会往右歪 |
| 空格写成 `num1 - i + 1` 或 `num1 - i - 1` | 整体左右偏一格 |
| 字符不加 `setw(2)` | 每行宽度不一致，右边缘不齐 |

## 编译运行

```bash
g++ src/char_triangle.cpp -o builds/char_triangle && ./builds/char_triangle
```
