# Exp4-03 区间内满足三个同余条件的整数

实验 4 第 3 题。

## 题目

从键盘输入两个正整数 m 和 n（大小关系不确定），找出区间内（含两端）除以 3 余 2、除以 5 余 1、除以 7 余 4 的所有整数，并输出个数。要求使用 `for` 语句。

## 语言

C++（`src/congruence_range.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/congruence_range.cpp -o builds/congruence_range
./builds/congruence_range
```

## 运行示例

输入 `10 400`：

```
请输入整数范围m和n:10 400
11
116
221
326
共有4个满足条件的整数
```

输入 `600 200`（顺序反过来）：

```
请输入整数范围m和n:600 200
221
326
431
536
共有4个满足条件的整数
```

## 要点

- `m`、`n` 的大小关系不确定，所以先用条件运算符归一：`hi = (a > b) ? a : b`，`lo = (a < b) ? a : b`。少了这一步，输入 `600 200` 时循环一次都不会走。
- `for` 圆括号里是**三段用分号隔开**的表达式：初始化、继续条件、步进。中间那段回答的是「**还要不要继续**」，不是「什么时候结束」。写成 `i <= hi`，不是 `i == hi`——用 `==` 只有在首尾相等时才会进循环。
- 题目要求「除以 3 余 2」这种条件，本质就是 `i % 3 == 2`。三个条件必须同时成立，所以用 `&&` 连接。
- 范围包含两个端点，所以条件是 `i <= hi`，不能写成 `<`。
- 这类题的标准解是「中国剩余定理」，11 是最小的解，之后每隔 105（3×5×7）出现一次。程序穷举即可，不必手算。
