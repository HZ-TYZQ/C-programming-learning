## 循环三要素

写任何循环之前，先把这三件事想清楚：

| # | 要素 | `while` 里 | `for` 里 |
| --- | --- | --- | --- |
| ① | 初始化 | `int i = 1;` | `for (int i = 1; ...)` |
| ② | 条件 | `while (i <= 10)` | `for (...; i <= 10; ...)` |
| ③ | 更新 | 循环体里 `i++;` | `for (...; ...; i++)` |

**缺了 ③ 就是死循环。** 缺了 ① 会从垃圾值开始。

## 几个容易踩的点

**条件是"继续的条件"，不是"停止的条件"。** 想打印 1~10 就要写 `i <= 10`；
写成 `i > 10` 会让循环一次都不执行。

**差一错误（off-by-one）。** `i < 10` 只转 9 次，`i <= 10` 转 10 次。
程序不会报错，只是结果差一个 —— 测试时一定要检查边界。

**累加从 0 开始，累乘从 1 开始。** 因为 `0 × 任何数 = 0`。

**累加器每轮之前要清零。** 否则第二次统计会把上一次的结果叠上来。

**`for (int i = ...)` 里声明的 `i`，出了 `for` 就不能用了**（会报 `C2065`）。
要在外面用，就先在外面声明。

**`i % 2 != 1` 判偶数有隐患。** 对正数没问题，但 `-3 % 2` 在 C++ 里是 `-1`，
`-1 != 1` 为真，负数奇数会被误判成偶数。**用 `i % 2 == 0` 更可靠。**
