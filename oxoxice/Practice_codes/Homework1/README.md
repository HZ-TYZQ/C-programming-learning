## 踩过的坑（都踩过一遍才对）

**① 整数除法丢小数。**
`(double)a / 3600 / 24 * 100` 里 `(double)` 必须在除法**之前**，
写成 `(double)(a / 3600 / 24) * 100` 就是 0。

**② C++ 没有「区间」这种写法。**
`0 < w <= 1` 会被解析成 `(0 < w) <= 1`，而 `(0 < w)` 是 bool，
`0 <= 1` 和 `1 <= 1` 都成立，所以**永远为真**。
编译器只给 `warning C4804`（在操作中使用类型 bool 不安全），不会报错，非常隐蔽。

正确做法是利用 `else if` 的互斥性，**每个分支只写上界（或下界）**：

```cpp
if (w <= 0)        // 先排除非法
else if (w > 5)    // 再处理最大的一段
else if (w > 1)    // 往下递
else               // 兜底
```

**③ 变量忘了初始化。**
`int fact, sum;` 之后直接用，读到的是内存里的垃圾值（`warning C4700`）。
累加从 `0` 开始，累乘从 `1` 开始。

**④ 循环起点错了。**
`for (int i = 0; i <= n; i++)` 里，`i = 0` 时 `fact = fact * 0` 会把阶乘直接清零。
`1!` 是第 1 项，所以必须从 `i = 1` 开始。

**⑤ `setprecision` 对整数不起作用。**
`cout << 10` 永远是 `10`，不会变成 `10.00`。
要输出两位小数，写的那个数本身得是浮点：`10.0` 而不是 `10`。
