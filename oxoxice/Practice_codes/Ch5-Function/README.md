## 函数三要素

```cpp
返回类型  函数名(参数表)
{
    函数体
    return 返回值;
}
```

写之前先回答三个问题：

1. 它需要什么材料？ → 参数表
2. 它要干什么活？ → 函数体
3. 它交出什么结果？ → 返回类型 + `return`

## 易错点

1. `for` 的三段之间是**分号**，不是逗号：`for (int i = 1; i <= n; i++)`
2. `for` 中间那段是**继续条件**，条件成立才继续下一轮
3. 判断相等用 `==`；`=` 是赋值，写进 `if` 里是经典 bug
4. **值传递是「复印」**：函数里改形参，调用处的实参不会变
5. 要交出结果就用 `return`，别指望通过参数带出去
6. 非 `void` 函数**每条执行路径**都要有 `return`，否则返回垃圾值
7. 函数要自己处理边界：`isPrime` 必须挡住 0、1 和负数
8. 递归必须有终止条件，且每次调用参数要**变小**
9. 代码里的分号、逗号、括号必须是**半角**（英文）符号，全角会直接编译报错

## 递归的两个阶段

```cpp
long long factorial(int n)
{
    cout << "进入 n=" << n << endl;   // 写在递归调用之前 → 由外往内执行
    if (n == 0) return 1;
    return n * factorial(n - 1);
}
```

把打印语句移到 `return` 之后，输出顺序会完全反过来（由内往外）。这说明递归函数里：

- 写在递归调用**之前**的语句，按从外层到内层的顺序执行
- 写在递归调用**之后**的语句，按从内层到外层的顺序执行
