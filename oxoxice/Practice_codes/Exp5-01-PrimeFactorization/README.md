# 实验 5 第 1 题：质因数分解

## 题目

从键盘输入一个**合数**，采用**单层循环**对这个合数进行质因数分解。

> 合数：自然数中除了能被 1 和本身整除外，还能被其他数（0 除外）整除的数。

## 输入输出样例

```
请输入n: 420
420=2*2*3*5*7
```

```
请输入n: 230
230=2*5*23
```

## 思路

从 2 开始试因子：

1. `a` 能整除 `n` → 输出 `a`，然后让 `n = n / a`
2. 除完以后 `a--`，因为**同一个因子可能还能再除一次**（420 里面有两个 2）
3. 只有 `n != 1`（还没除完）时才输出 `*`

例：420 → 除 2 得 210 → 再除 2 得 105 → 除 3 得 35 → 除 5 得 7 → 除 7 得 1

## 易错点

| 坑 | 后果 |
| --- | --- |
| 循环上界写成 `a < n / 2` | `n` 一直在变小，这个上界会把循环提前掐断，漏掉最后一个因子（420 会输出成 `2*2*3*5*`） |
| 先打 `*` 再打因子 | 末尾会多一个孤零零的乘号 |
| 忘了 `a--` | 同一个因子只会输出一次，420 会变成 `2*3*5*7`，少一个 2 |

正确写法是循环继续到 `a <= n`：`n` 每次都被除小，循环自己会停下来。
