## 一、累和累积（考纲第 1 类）

### 1. 加减规律组项求和

求 `1 - 1/2 + 1/3 - 1/4 + … ` 前 100 项之和，输出保留 4 位小数。

```
输出：0.6882
```

**考点**：符号交替（`(-1)^(i+1)` 或用一个 `sign = -sign` 翻转）、浮点除法。

### 2. a + aa + aaa + …

输入 `a`（1~9）和 `n`，求 `a + aa + aaa + …`（n 项）之和。

```
输入：2 3
输出：246
```

因为 `2 + 22 + 222 = 246`。

**考点**：用 `t = t * 10 + a` 递推每一项，不需要数组。

### 3. 用级数求 π

```
π/4 = 1 - 1/3 + 1/5 - 1/7 + …
```

一直加到某一项的绝对值小于 `1e-6` 为止，输出 π 的值（保留 6 位小数）。

```
输出：3.141591
```

**考点**：`while` + 精度控制、符号翻转、分母每次 +2。

### 4. 用级数求 e

```
e = 1 + 1/1! + 1/2! + 1/3! + …
```

一直加到某一项小于 `1e-6` 为止，输出 e（保留 6 位小数）。

```
输出：2.718282
```

**考点**：阶乘项的**递推**——`t = t / i`，不要每次都重新算 `i!`。

## 二、数论类（考纲第 2 类）

### 5. 回文数

输出 `100 ~ 999` 之间所有的回文数，**每行 10 个**，每个宽度 5。

```
   101   111   121   131   141   151   161   171   181   191
   202   212   …
```

**考点**：取数字（`n/100`、`n/10%10`、`n%10`）、`setw(5)`、计数器换行。

> 实验 5 第 5 题就是这个，只是多了「个位不为 3」和「区间由输入决定」。

### 6. 互质数

输出 `1 ~ 100` 之间所有与 `12` 互质的整数（每行 10 个）。
> 互质：两个数的最大公约数为 1。

**考点**：在 `main` 里直接用辗转相除求 gcd（本次不考函数，所以不要另写函数）。

### 7. 十进制转二进制

输入一个正整数，输出它的二进制形式（不许用数组，不许用函数）。

```
输入：13
输出：1101
```

**考点**：**这题的关键是「从高位往低位取」**。先求出不超过 n 的最大 2 的幂，再一位一位往下取：

```
最高权值 p = 1
当 p * 2 <= n：p = p * 2
然后 p 每次除以 2，判断 n 里有没有这一位，有就输出 1，没有就输出 0
```

### 8. 十进制转八进制

输入一个正整数，输出它的八进制形式（同样不许用数组）。

```
输入：83
输出：123
```

**考点**：和第 7 题同一个套路，只是权值每次乘 8、除 8。

## 三、枚举法（考纲第 4 类）

### 9. 百钱百鸡

公鸡 5 钱一只，母鸡 3 钱一只，小鸡 1 钱 3 只。
用 100 钱买 100 只鸡，问公鸡、母鸡、小鸡各几只？列出所有方案并统计种数。

```
输出：
公鸡 0 只，母鸡 25 只，小鸡 75 只
公鸡 4 只，母鸡 18 只，小鸡 78 只
公鸡 8 只，母鸡 11 只，小鸡 81 只
公鸡 12 只，母鸡 4 只，小鸡 84 只
共有4种买法
```

**考点**：双重循环枚举 + 两个约束同时满足；小鸡数必须是 3 的倍数。

> 实验 5 第 4 题（搬砖）就是这一类，先写那道。

## 四、输出图形（考纲第 5 类）

### 10. 菱形

输入行数（奇数）和一个字符，输出由该字符构成的菱形。

```
输入：5 #
    #
   # #
  # # #
 # # # #
# # # # #
 # # # #
  # # #
   # #
    #
```

**考点**：把菱形拆成「上半 + 下半」两段循环；空格按 1 个补，字符按 2 列算。

## 五、选择结构补充（考纲开头）

### 11. 成绩等级（switch）

输入一个 0~100 的整数成绩，用 `if / else if` 和 `switch` **两种写法**各输出一次等级：

```
90~100  → A
80~89   → B
70~79   → C
60~69   → D
0~59    → E
其它    → 输入错误
```

**考点**：`switch` 只能判断整数，所以要把成绩**除以 10 取整**再配 `case`；注意 100 分要单独处理（`100/10 = 10`）。
