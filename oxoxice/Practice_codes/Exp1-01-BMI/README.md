# Exp1-01 BMI 身体质量指数

实验 1 第 1 题。

## 题目

输入某人的身高（米）和体重（公斤），求其身体质量指数 BMI。

```
BMI = 体重 / 身高²
```

## 语言

C++（`src/bmi.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/bmi.cpp -o builds/bmi
./builds/bmi
```

## 运行示例

输入身高 `1.72`、体重 `75.5`：

```
请输入身高（米）1.72
请输入体重（公斤）：75.5
此人的身体质量指数为：25.5206kg/m*2
```
