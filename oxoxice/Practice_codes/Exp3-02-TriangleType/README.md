# Exp3-02 判断三条边能否构成三角形及类型

实验 3 第 2 题。

## 题目

从键盘输入三角形的三条边长，判断是否能构成三角形。如果是，继续判断能构成哪种三角形（等边、等腰、一般）。不需考虑是否能构成直角三角形。

要求使用 `if-else` 嵌套语句实现多路分支结构。

## 语言

C++（`src/triangle_type.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/triangle_type.cpp -o builds/triangle_type
./builds/triangle_type
```

## 运行示例

输入 `3 4 5`：

```
请输入三角形的三条边长：3 4 5
可以构成一般三角形
```

输入 `3 4 9`：

```
请输入三角形的三条边长：3 4 9
不能构成三角形
```

输入 `3 3 5`：

```
请输入三角形的三条边长：3 3 5
可以构成等腰三角形
```

输入 `4 4 4`：

```
请输入三角形的三条边长：4 4 4
可以构成等边三角形
```

## 要点

- 这道题有两个判断层次，必须先判「能不能构成」，再判「是哪一种」，所以外层是 `if` 里套 `if`。题目写的是「如果是，继续判断」，顺序不能颠倒。
- 能否构成三角形：任意两边之和大于第三边，即 `a + b > c && a + c > b && b + c > a`。
- **等边一定也是等腰**，所以「等边」必须排在「等腰」前面，而且两者之间要用 `else if` 连接。写成两个并列的 `if`，输入 4 4 4 会同时输出「等边」和「等腰」两行。
- 输入要用 `cin >> a >> b >> c;`。写成 `cin >> a, b, c;` 的话逗号运算符只会读入 `a`，`b` 和 `c` 是未初始化的垃圾值，所有判断都会失败、永远走 `else`（编译时会出现警告 C4700：使用了未初始化的局部变量）。
- 边长必须为正数，`0 0 0` 和负数应该报错，否则 0 0 0 会被判成等边三角形。
