# Exp3-01 按显存判断可运行的 AI 任务

实验 3 第 1 题。

## 题目

输入显卡显存大小（单位 GB，支持小数），按显存容量判断可执行的 AI 任务：

| 显存 | 可执行的任务 |
| --- | --- |
| ≥ 24GB | 可以运行大模型训练 |
| 10GB ≤ 显存 < 24GB | 可以运行模型微调 |
| 4GB ≤ 显存 < 10GB | 仅支持模型推理 |
| < 4GB | 显存不足，无法运行 AI 任务 |

要求使用 `if-else` 嵌套语句实现多路分支结构。

## 语言

C++（`src/vram_judge.cpp`）

## 编译与运行

```bash
mkdir -p builds
g++ src/vram_judge.cpp -o builds/vram_judge
./builds/vram_judge
```

## 运行示例

输入 `24`：

```
请输入显卡显存大小(GB)：24
可以运行大模型训练
```

输入 `16`：

```
请输入显卡显存大小(GB)：16
可以运行模型微调
```

输入 `8`：

```
请输入显卡显存大小(GB)：8
仅支持模型推理
```

输入 `3.2`：

```
请输入显卡显存大小(GB)：3.2
显存不足，无法运行AI任务
```

## 要点

- 四个档位是四个相邻区间，端点 24、10、4 在相邻两档之间重复出现。用 `else if` 排成阶梯，**从大到小**判断，每个分支只写下限就够了——能走到 `else if (vram >= 10)` 这一行，就说明 `vram >= 24` 已经失败，也就是 `vram < 24` 已经成立，上限不需要再写一遍。
- 顺序不能反。如果把最松的 `vram >= 4` 放在最前面，24 和 16 都会被它抢先命中，全部判成「仅支持模型推理」。
- 题目要求支持小数，变量必须是 `double`。用 `int` 的话输入 3.2 会被截断成 3。
- 边界值是判断重点：`10` 属于微调档，`9.99` 掉到推理档；`4` 属于推理档，`3.99` 属于显存不足。条件里的 `>=` 不能写成 `>`。
