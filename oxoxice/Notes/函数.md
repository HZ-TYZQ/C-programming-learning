# 第 5 章 函数

> 学习笔记。对应练习在 `../Practice_codes/Ch5-Function/`，踩坑汇总在 [踩坑记录.md](踩坑记录.md)。

## 一、为什么需要函数

同一个计算要做三遍，复制三遍循环体，改的时候要改三处 —— 这就是要函数的理由。

> 把「做一件事」的代码打包，起个名字，以后一行就能用。

```cpp
int countInRange(int m, int n);   // 打包
cout << countInRange(1, 100);     // 用一次
cout << countInRange(50, 200);    // 再用一次，没多写一行
```

## 二、函数的骨架

```cpp
返回类型  函数名(参数表)
{
    函数体
    return 返回值;
}
```

写之前先回答三个问题：

| 问题 | 对应 |
| --- | --- |
| 它需要什么材料？ | 参数表 |
| 它要干什么活？ | 函数体 |
| 它交出什么结果？ | 返回类型 + `return` |

```cpp
// 求两个整数的较大者
int maxOf(int a, int b)
{
    if (a > b) return a;
    else       return b;
}
```

术语：

- `int a, int b` 是**形参**（函数内部的临时变量）
- `maxOf(x, y)` 里的 `x`、`y` 是**实参**（真正交进去的数据）

## 三、`void`：只干活，不交结果

```cpp
void printLine(int n)
{
    for (int i = 0; i < n; i++) cout << '-';
    cout << endl;
}
```

`void` 函数里可以写 `return;`（提前结束），但**不能** `return 一个值`。

## 四、声明与定义

编译器从上往下读。函数写在 `main` 后面时，要先声明：

```cpp
int maxOf(int a, int b);        // 声明：末尾分号，没有大括号

int main()
{
    cout << maxOf(3, 5) << endl;
    return 0;
}

int maxOf(int a, int b)         // 定义：有大括号，末尾没分号
{
    if (a > b) return a;
    else       return b;
}
```

> **声明带分号没大括号，定义有大括号没分号。**

## 五、值传递：最容易错的地方

```cpp
void swapWrong(int a, int b)
{
    int t = a;
    a = b;
    b = t;
}

int main()
{
    int x = 3, y = 8;
    swapWrong(x, y);
    cout << x << " " << y;      // 3 8，没换过来
    return 0;
}
```

> **值传递 = 复印一份交进去。函数里改的是复印件，原件不动。**

两个后果：

1. 函数里改变参数，外面看不见
2. 要让函数交出结果，只能用 `return`

## 六、作用域

| 变量定义在哪 | 谁能用 |
| --- | --- |
| 函数内部 | 只有这个函数能用 |
| `main` 内部 | 只有 `main` 能用（其他函数看不见） |
| 所有函数外面（全局） | 谁都能用，但不推荐 |

同名变量可以共存，里层会「盖住」外层，这叫**遮蔽（shadowing）**：

```cpp
int x = 10;
for (int i = 0; i < 3; i++)
{
    int x = i;          // 另一个 x，只活在这对大括号里
    cout << x;          // 012
}
cout << x;              // 10，外层从没被改过
```

## 七、递归

> 一个函数在自己的函数体里调用自己。

| | 循环 | 递归 |
| --- | --- | --- |
| 怎么重复 | 用 `while`/`for` 转圈 | 把问题变小一号，交给自己 |
| 什么时候停 | 循环条件不成立 | 撞到终止条件 |
| 思考方式 | 「第 1 步、第 2 步、第 3 步」 | 「要算 n，得先知道 n-1」 |

必备两个零件：

```
① 终止条件：最小的那种情况，直接给答案
② 递推关系：大问题怎么变成小一号的问题
```

### 阶乘

```
0! = 1
n! = n × (n-1)!
```

```cpp
long long factorial(int n)
{
    if (n == 0) return 1;              // ① 终止条件
    return n * factorial(n - 1);       // ② 参数小一号
}
```

### 执行过程（两个阶段）

```
factorial(4) = 4 * factorial(3)
                    ↓
               factorial(3) = 3 * factorial(2)
                                   ↓
                              factorial(2) = 2 * factorial(1)
                                                 ↓
                                            factorial(1) = 1 * factorial(0)
                                                              ↓
                                                         factorial(0) = 1  ← 到底
```

然后从下往上返回：`1 → 1 → 2 → 6 → 24`。

**先一路往下钻，钻到底再一路弹回来。**

### 用打印语句验证阶段

```cpp
long long factorial(int n)
{
    cout << "进入 n=" << n << endl;   // 调用之前 → 由外往内 5 4 3 2 1 0
    if (n == 0) return 1;
    return n * factorial(n - 1);
}
```

把 `cout` 挪到 `return` 之后，顺序变成 `0 1 2 3 4 5`（由内往外）。

## 八、递归的两面

同一个问题的两种写法，以最大公约数为例：

```cpp
// 循环版
int gcd(int a, int b)
{
    while (b != 0)
    {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

// 递归版
int gcd(int a, int b)
{
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

递归版更短、更贴数学定义；循环版更省内存。

### 递归什么时候会慢

慢的不是「递归」本身，而是**重叠子问题**——同一个子问题被算了无数遍。

| 例子 | 子问题重复吗 | 结论 |
| --- | --- | --- |
| 阶乘 | 不重复 | 递归很快 |
| 汉诺塔 | 不重复 | 该用递归 |
| 斐波那契 | 大量重复 | 递归是灾难 |

斐波那契递归调用次数：

| n | 调用次数 |
| --- | --- |
| 20 | 约 2 万 |
| 30 | 约 270 万 |
| 40 | 约 3.3 亿 |

每增加 1 → 乘 1.618；每增加 5 → 乘 11。

解决方向是**记忆化**：第一次算出来存进数组，之后直接查表（数组在下一章）。

## 九、易错速查

| 错误写法 | 正确写法 |
| --- | --- |
| `int add(int a, b)` | `int add(int a, int b)` |
| `add(int 3, int 4)` | `add(3, 4)` |
| `for (int i = 1, i <= 10, i++)` | `for (int i = 1; i <= 10; i++)` |
| `for { ... }` | `for ( ... )` |
| `return0;` | `return 0;` |
| `if (a = b)` | `if (a == b)` |
| 非 void 函数少一条 return | 每条路径都要有 |

## 十、一句话总结

> **函数只做一件事：拿到输入，算出结果，用 `return` 交出去。**
> **递归只要记住：先写终止条件，再让参数变小。**
