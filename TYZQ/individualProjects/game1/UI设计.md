# 《下一站，生日》终端 UI 设计决策

对应策划：[游戏策划.md](./游戏策划.md)  
对应架构：[代码架构设计.md](./代码架构设计.md)

## 1. 核心决策与技术边界

本次确定采用**简洁版终端 UI 方案**，兼顾视觉小说观感、操作顺手度与代码可读性，全部基于 C11 与已学课程内容（UESTC1005 Lecture 1–12）实现：

- **不引入复杂终端底层 API**：不使用 `<termios.h>`、`select()`、信号处理或 `ncurses`，不切换 raw mode。
- **编译环境**：Linux 终端，`gcc -std=c11 -Wall -Wextra -Wpedantic -g`。
- **唯一课外辅助函数**：在 `ui.c` 的**绝对第 1 行（所有 `#include` 之前，绝不写入任何 `.h` 文件）**定义 `#define _POSIX_C_SOURCE 200809L`，配合 `<time.h>` 的 `nanosleep()` 封装 `sleepMs(int ms)`，实现逐字打字机停顿。
- **安全输入与 EOF 处理**：延续 `Course11Practice/src/input.c` 的 `fgets` + `strtol` + 行尾检测模式（兼容 `\r\n` 与无末尾换行的管道输入），不依赖裸 `scanf`。所有输入函数均明确区分**正常输入、取消操作与输入流结束（`EOF`）**，遇到 `EOF` 时向上干净退出程序，不误触发取消或死循环。

## 2. 防刷屏与视觉排版规范

### 2.1 单屏原地重绘与安全提示栏

- 切换界面（主菜单、选星、市场、事件、剧情、结局）以及在市场内完成单次买卖后，均通过 ANSI 转义序列清屏并归位光标：
  ```c
  printf("\x1b[2J\x1b[H");
  fflush(stdout);
  ```
- 界面内仅保留**一行最新操作反馈（`notice`）**，杜绝历史菜单不断向上刷屏。
- **防乱码/防串色约定**：提示缓冲区采用 `char notice[256]`，并将提示等级（`enum NoticeKind`：`NOTICE_INFO` / `NOTICE_OK` / `NOTICE_WARN` / `NOTICE_ERR`）与纯文本分开存储，由 `drawStatusHeader()` 统一包裹对应颜色与 `C_RESET`，避免 `snprintf` 截断 3 字节 UTF-8 汉字或截掉结尾重置码。

### 2.2 开放式横线框架

- 面板统一采用上下水平分割线（`━` 为主分割，`─` 为次分割，宽度 **72 列**，契合标准 80 列终端），**不绘制右侧竖边框**。
- 优点：视觉干净现代，且天然规避中文全角字符与 ASCII 混排时的右边框对齐问题。

### 2.3 克制的 ANSI 配色方案

| 用途                           | 颜色样式     | ANSI 宏           |
| ------------------------------ | ------------ | ----------------- |
| 分割线、次要提示、不可选灰项   | 暗灰         | `\x1b[90m`        |
| 旁白叙述                       | 暗灰斜体     | `\x1b[90m\x1b[3m` |
| 标题、快捷键编号、渡里姓名     | 青色（加粗） | `\x1b[36m`        |
| 资金数值、蕾德莉姓名、事件选项 | 暖黄（加粗） | `\x1b[33m`        |
| 成功结算、NPC 姓名、资金达标   | 绿色         | `\x1b[32m`        |
| 错误提示、警告                 | 红色         | `\x1b[31m`        |
| 内心独白、特殊信物与回忆       | 淡紫         | `\x1b[35m`        |
| 对话正文                       | 亮白         | `\x1b[97m`        |

## 3. 视觉小说打字机规范

### 3.1 UTF-8 逐字输出

- UTF-8 中一个中文字符占 3 字节，其后续字节均满足 `((unsigned char)ch & 0xC0u) == 0x80u`（位掩码判断）。
- 每次输出首字节后，用 `while` 循环把同一字符的续字节一并输出，**统一使用 `putchar((unsigned char)text[i])`** 避免负 `char` 符号扩展，随后 `fflush(stdout)` 与 `sleepMs()`，保证汉字逐字弹出且绝不乱码。

### 3.2 语速与标点呼吸感

- 提供三档语速并支持随时切换：`0 = 正常`、`1 = 快速`（延迟除以 3）、`2 = 即时`（跳过停顿）。
- 正常档参考节奏（适配 16 份剧本的半角标点约定，同时兼容全角标点与破折号）：
  - 普通汉字：`25 ms`；普通 ASCII：`18 ms`。
  - 逗号 `,` / `，`：额外 `+120 ms`。
  - 单个句号 `.` / 感叹号 `!` / 问号 `?`（及全角 `。` / `！` / `？`）：额外 `+170 ms`。
  - 省略号 `...`（当 `.` 的前或后紧邻 `.` 时）：每点额外 `+70 ms`（3 点合计约 260 ms，避免过分拖沓）。
  - 破折号 `——`：额外 `+90 ms`。

### 3.3 台词类型、流式拼接与物理行翻页规则

- 台词结构 `struct StoryLine`（定义在 `ui.h`）区分 6 种样式：`LINE_NARRATION`（旁白）、`LINE_RIDLEY`（蕾德莉）、`LINE_WATARI`（渡里）、`LINE_NPC`（星球角色）、`LINE_THOUGHT`（内心独白）、`LINE_BREAK`（场景过渡 `· · ·`）。
- **流式页面上下文（`struct StoryContext`）**：
  - 提供 `storyBegin(&ctx, title)`、`storyPlayChunk(&ctx, lines, count)`、`storyWaitEnd()`。
  - 同一场戏中需要按条件拼接的多个剧本段（如 `day5_1`~`day5_4`、`ending1`、`ending2`、`planet4`）共享同一个 `StoryContext`（共享当前页已占行数），**绝不因分段调用而强制清屏**；仅在场景明确切换处（如 `day5_4` 切回飞船前）插入 `LINE_BREAK`。
- **按物理折行估算翻页**：
  - 剧本中部分长句可达 90～115 显示列，按固定“10 句”翻页会在 80×24 终端顶出标题栏。
  - 改为估算每句物理行数（ASCII 字符算 1 列，UTF-8 非续字节多字节字符算 2 列，加上说话人前缀后按每 70 列折 1 行向上取整），单页累计达到 **12～14 物理行** 时自动清屏翻页；遇到 `LINE_BREAK` 且当前页已过半时也可顺势换页。
- **步进交互（禁止跳过事件）**：
  - 标题栏轻量提示：`Enter 下一句 | f 切语速 | s 本段即时显完（打字期间请勿连按 Enter）`。
  - 正式剧情**移除 `q` 退出跳过**，防止玩家误跳事件决策或结算；输入 `s + Enter` 仅将当前片段剩余台词以即时模式快速输出完毕，随后正常进入选项或结束等待。
  - `waitStoryStep()` 返回 `enum StoryStep`（`STEP_NEXT` / `STEP_SPEED` / `STEP_SKIP_CHUNK` / `STEP_EOF`），切语速后在下次翻页或顶栏同步最新语速名称。

## 4. 核心界面与操作流设计

### 4.1 常驻状态顶栏（选星 / 市场共用）

固定置于屏幕最上方，保持空间记忆：

- 第 1 行：`Day X / 5  |  当前界面/星球  |  今日余程: 剩余/2`
- 第 2 行：`资金: 当前 / 720 G`（达到 720 G 时以绿色标注）`  货舱: 已用/上限  信物/回忆: ...`
  - **信物/回忆展示规则**：持有干花书签且未写花名显示 `[干花书签]`；保留书签解锁话题后显示 `[干花书签·花名]`；持有黄铜钥匙显示 `[黄铜钥匙]`；换出星图解锁话题后显示 `[生日星图]`；皆无时显示 `无`。
- 分隔线下方：单行最新提示 `notice`（按 `NoticeKind` 统一着色）。

### 4.2 界面操作逻辑（扁平、少按键、防误操）

1. **标题主菜单**
   - `[1] 开始新旅程`（若当前已存在有效存档，弹出二次确认防止误覆盖旧档）
   - `[2] 继续旅程`（存在有效存档时显示含阶段与星球的摘要，如 `Day 3 · 钟之星 · 340 G` 或 `Day 5 · 生日购礼 · 750 G`；无存档或损坏时置灰提示）
   - `[3] 切换打字速度（正常 / 快速 / 即时）`
   - `[0] 退出游戏`

2. **开局选择起点**
   - 顶部显式标明：`目标: 五天内攒足 720 G 买甜之星巧克力 | 资金: 80 G | 货舱: 5 格 | 起点不触发抵达事件`。
   - 5 颗贸易星以紧凑 2 行格式展示直达航线与买卖行情（整屏约 18 行，一屏完整呈现），玩家选 `1~5` 确认后直接进入当地市场备货。

3. **选星主界面**
   - 展示当前货舱非空持货（空舱显示 `空舱`）。
   - 只列出**当前可直达的 2～3 颗邻星**，编号 `[1]`～`[N]`，附带各邻星收购/出售商品与价格；若玩家手持该星收购货物，高亮标注 `[可售]`。
   - 固定辅助项：`[4] 查看星图与完整行情`（弹页查看，按 Enter 返回）、`[9] 返回主菜单`（二次确认，提示本日未完成航程不保存）、`[0] 结束今日`（二次确认后跳过今日剩余航程进入当晚日常）。
   - **输入防越界**：在只有 2 颗邻星的星球（花/镜/运），显式拦截空号 `3` 并提示无效选项。
   - **第五天提前收工强警告**：第 5 天在选星界面选 `[0] 结束今日` 且 `getCargoUsed > 0` 时，二次确认以红色醒目警告「今日是最后一天，舱内仍有 X 件货物未卖出，提前收工将直接前往温泉与生日结算，未售货物不计入购礼资金，确认吗？」。

4. **市场交易界面**
   - **扁平直选**：直接列出 1 项收购货 + 1～2 项出售货 + `[9] 查看星图与完整行情`（查看完毕返回当前市场，不消耗回合）+ `[0] 离开市场`。
   - **顺流行情附注**：买入商品行后直接附注收购星与收价（例如 `买入 微缩胶卷 20 G/件 -> 镜之星收 45 G`），无需频繁切屏查表。
   - **不可用项置灰**：持货为 0 的卖出项、满仓或资金不足的买入项以 `C_GRAY` 渲染并标明 `(未持有)` / `(满仓)` / `(资金不足)`。
   - **一键全卖 / 买满**：选定有效商品后提示 `数量 [1~max, 直接回车=max, 0=取消]: `，空回车默认最大值成交，`0` 取消。
   - **第五天终站提醒**：第 5 天最后一站（`day == 5 && tripsLeft == 0`）离开市场时，若货舱仍有未售出货物，弹出确认提示「舱内未卖出的货物不计入购礼资金，确认离开吗？」；若本站恰好收购舱内某货，额外提示「本站可卖出 XXX 获得 +YYY G」。

5. **抵达事件界面**
   - 先用流式打字机播放抵达情景（镜之星曾暂缓离开重返时播 2 句短重逢开场）。
   - 选项框上方固定打印一行状态摘要：`当前: 资金 %d G | 货舱 %d/%d` + 本事件相关货物持有量（如 `| 安神花茶: %d`）。
   - 不满足条件的选项（缺货/缺钱）以 `C_GRAY` 置灰并标明原因（如 `[需安神花茶 x1]` / `[需资金 >= 50 G]`），输入该编号时拦截并重选。
   - **特例保护**：
     - 运之星满仓时**保持选项 2 可选**（仅需资金 `>= 50 G`），在选项后提示 `(满仓未中奖折现 25 G)`；
     - 镜之星已携带微缩胶卷时**隐藏/禁用选项 3「暂缓离开」**，仅未携带微缩胶卷时开放。
   - 选定后同一页面上下文续播对应分支剧情与绿色结算提示，按 Enter 进入当地市场。

6. **每日自动存档、第五天温泉与生日结局**
   - 第 1～4 天晚间日常与第 5 天温泉结束后，执行自动存档并显示绿色提示 `[进度已自动保存: Day X · XXX G]`（若写入失败则红色警告），按 Enter 继续。
   - 生日购礼界面展示当前现金余额与两个选项（甜之星巧克力 `720 G` / 纸之星手作纸 `150 G`，余额 `< 720 G` 时甜之星置灰不可选）。
   - 结局播完后绘制**终章结算卡**（结局标题、购礼后剩余零花钱、已解锁温泉回忆），提示「已保留第五天温泉后存档，可在主菜单选择继续旅程重选礼物」，按 Enter 返回主菜单。

## 5. 模块接口约定（与 `代码架构设计.md` 严格对齐）

- `input.h / input.c`：
  - `enum StoryStep { STEP_NEXT, STEP_SPEED, STEP_SKIP_CHUNK, STEP_EOF }`
  - `int readIntInRange(const char *prompt, int minVal, int maxVal, int *outVal)`
  - `int readQuantityDefaultMax(const char *prompt, int maxVal, int *outQty)`（返回 `1` 成功、`0` EOF，与 `0` 取消彻底分离）
  - `enum StoryStep waitStoryStep(void)` / `int waitEnter(const char *prompt)` / `int confirmAction(const char *prompt)`
- `ui.h / ui.c`：
  - `enum LineType`、`struct StoryLine`、`struct StoryContext`、`enum NoticeKind`
  - ANSI 颜色与 72 列分割线宏、`clearScreen()`、`sleepMs()`
  - `getSpeedMode()` / `cycleSpeedMode()` / `getSpeedName()`
  - `typePrint()`、`storyBegin()` / `storyPlayChunk()` / `storyWaitEnd()`
  - `drawStatusHeader()`、`drawStartPlanetScreen()`、`drawTravelScreen()`、`drawStarMap()`、`drawMarketScreen()`、`drawBirthdayScreen()`、`drawEndingSummary()`
