## 1. 什么是数组（Array）【课件重点】

- 单个 `int score` 只能保存一个整数（标量，scalar）。
- `int scores[10];` 可以保存 **10 个同类型的整数**；它们按顺序存放在连续的内存位置中。
- 每个位置叫**元素（element）**；访问位置使用**下标（index）**。

```c
int scores[5];

scores[0] = 85;   // 第一个元素
scores[1] = 90;   // 第二个元素
scores[4] = 60;   // 第五个元素
```

**重要边界：**一个长度为 `n` 的数组，合法下标范围是 **`0` 到 `n - 1`**；访问 `scores[n]` 属于越界，会导致未定义行为。

```text
下标:        0    1    2    3    4
scores:     85   90   76   90   60
学生显示编号:  1    2    3    4    5
```

数组下标可以是表达式，如 `scores[i]`、`scores[i + 1]`、`scores[5 - 3]`。

## 2. 数组大小与遍历【课件重点】

```c
#define MAX_STUDENTS 10
int scores[MAX_STUDENTS] = {0};
int n = 3;   // 实际录入人数

for (int i = 0; i < n; i++) {
    printf("Student %d: %d\n", i + 1, scores[i]);
}
```

- `MAX_STUDENTS`：数组**容量**，为 10。
- `n`：当前**有效数据量**，可以小于 10。
- `i < n`：仅遍历已录入数据；不能因为数组容量是 10 就固定循环 10 次。
- `#define` 宏常用于固定数组容量，惯例使用大写字母。
- 课件还提到了 VLA（变长数组）和后续的动态分配，但未要求此处深入指针与内存分配。

## 3. 数组初始化【课件重点】

```c
int a[5] = {13, 22, 12, 18, 20};  // 全部显式初始化
int b[5] = {13, 22};              // 其余元素初始化为 0
int c[5] = {0};                   // 全部初始化为 0
int d[] = {13, 22, 12};           // 编译器推断长度为 3
int e[5] = {[4] = 34, [0] = 2};   // C99 指定初始化器
```

`e` 最终为 `{2, 0, 0, 0, 34}`。指定初始化器让我们可以按下标指定某些位置的初始值。

**易错点：**局部数组 `int a[5];` 未经初始化时，元素值不确定，读取前必须先赋值。

**【补充辨析：课件笔误】** 课件示例 `int grades[5] = {13, 22, 12, 18, 20};` 的第四个元素是 `grades[3] == 18`，不是 20；`grades[4] == 20`。

## 4. 数组作为函数参数【课件重点】

课件强调函数原型、函数定义、函数调用的区分，并建议在数组参数之外**额外传入数组长度**。

```c
void display_scores(int scores[], int n);  // 函数原型

int main(void) {
    int scores[3] = {85, 90, 76};
    display_scores(scores, 3);              // 函数调用：传数组名
    return 0;
}

void display_scores(int scores[], int n) { // 函数定义
    for (int i = 0; i < n; i++) {
        printf("Student %d: %d\n", i + 1, scores[i]);
    }
}
```

- **调用时传 `scores`，不是 `scores[]`**。
- 课件把这种效果称为 *pass by reference*：函数接收到数组首元素的地址，可以修改原数组元素。
- **【补充辨析】更严格地说：C 语言仍然是按值传参；数组参数会调整为指针参数，传递的是首元素地址的副本，而不是把整份数组复制进函数。** 指针的完整原理留到 Lecture 8。
- 传单个元素（例如 `scores[0]`）给普通 `int` 形参，通常不会修改调用者中的原元素。

### 平均分与类型转换【课件示例与实战】

```c
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += scores[i];
}
double average = (double)sum / n;  // n 必须大于 0
printf("Average: %.2f\n", average);
```

若没有 `(double)`，`sum / n` 会先按整数除法求值，丢失小数部分。

## 5. 线性查找（Linear Search）【课件课堂任务】

课堂任务规定：从数组中查找一个值，**找到则返回数组下标；找不到返回 `-1`**。

```c
int search_array(int a[], int n, int target) {
    for (int i = 0; i < n; i++) {
        if (a[i] == target) {
            return i;
        }
    }
    return -1;  // 必须在循环结束后
}
```

- 从左到右逐项比较 `a[i] == target`。
- `return i;` 立即结束函数，因此返回的是**第一个**匹配位置。
- `return -1;` 要放在整个 `for` 循环之后，不能放在循环内的“不匹配”分支中。

### 查找所有匹配项【实战拓展】

你主动提出：把全部匹配结果记录到另一个数组，最后统一输出。这是课堂“查找第一个”的自然升级。

```c
int search_all_scores(int scores[], int n, int target, int found_indices[]) {
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (scores[i] == target) {
            found_indices[count] = i;  // 保存数组下标，不是 i + 1
            count++;
        }
    }
    return count;
}
```

示例：`{85, 90, 76, 90, 60}` 搜索 `90`，得到 `found_indices = {1, 3}`、`count = 2`，显示 Student 2 和 Student 4。结果数组的容量应至少为 `n`。

## 6. 排序（Sorting Algorithms）【课件重点】

- **升序（ascending）**：从小到大。
- **降序（descending）**：从大到小。
- 课件列举：冒泡、插入、快速、选择、归并、堆和基数排序等。
- 本讲主要示范**冒泡排序（Bubble Sort）**；课件的课后要求是实现冒泡排序以及自选的另一种排序算法。

### 冒泡排序：比较、交换、重复

核心操作是比较相邻元素，左侧更大时交换：

```c
if (scores[j] > scores[j + 1]) {
    int temp = scores[j];
    scores[j] = scores[j + 1];
    scores[j + 1] = temp;
}
```

每完成一趟，从左到右的比较会把尚未排好的最大值“推”到右端。

你在项目中写出的完整升序实现：

```c
void bubble_sort(int scores[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (scores[j] > scores[j + 1]) {
                int temp = scores[j];
                scores[j] = scores[j + 1];
                scores[j + 1] = temp;
            }
        }
    }
}
```

`i` 代表已完成的排序趟数；`j` 代表这一趟比较的左侧元素下标。

**为什么 `j < n - i - 1`？**

1. 比较时会读取 `scores[j + 1]`，它不能越过数组最后一个下标 `n - 1`。
2. 所以 `j + 1 <= n - 1`，即 `j < n - 1`。
3. 每一趟末尾又有一个元素确定位置，所以还可以减去 `i`，最终得到 `j < n - i - 1`。

### 冒泡排序的两条提醒

- 最多 `n - 1` 趟有效排序；外层写 `i < n` 也能排序，但最后一趟内循环为空。
- **【实战拓展】**普通冒泡排序最坏情况下需要约 `n(n-1)/2` 次相邻比较，时间复杂度为 `O(n²)`。这属于算法分析补充，不是本次课件的重点。

## 8. 常见易错点速查

| 典型问题 | 正确做法 |
|---|---|
| 数组从 1 开始访问 | C 数组下标从 **0** 开始 |
| 遍历 `i <= n` | 使用 `i < n` |
| 相邻比较导致越界 | 控制 `j + 1 < n - i` |
| 用容量代表有效人数 | 区分 `MAX_STUDENTS` 与 `n` |
| 局部数组声明后直接读 | 先初始化或逐个赋值 |
| `int` 除以 `int` 得到小数 | 先转成 `double` 或 `float` |
| 查找首次不匹配就返回 `-1` | 遍历结束后再返回 `-1` |
| 查找所有匹配结果却直接 `return i` | 保存下标并继续遍历 |
| 把学生编号与数组下标混用 | 显示编号用 `i + 1`；数组访问用 `i` |
