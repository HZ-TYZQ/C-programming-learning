## 1. Pointer Basics — 指针基础

### 1.1 指针是什么？

**指针是保存内存地址的变量。**

```c
int a = 10;
int* p = &a;
```

- `a`：整数变量，值为 10。
- `&a`：变量 a 的内存地址。
- `p`：指针变量，保存 a 的地址。
- `*p`：解引用，访问 p 指向的整数，也就是 a。

假设：

| 变量 | 自身地址 | 保存的内容 |
| ---- | -------- | ---------- |
| a    | `0x1000` | `10`       |
| p    | `0x2000` | `0x1000`   |

那么：

```c
p       // 0x1000
&p      // 0x2000
*p      // 10
```

**重点：`p` 保存的地址不等于 `p` 自身的地址。**

### 1.2 `*` 的两个作用

```c
int* p = &a;   // 声明指针
*p = 50;       // 解引用，修改 a 的值
```

在声明中，`*` 表示指针类型；在表达式中，`*` 表示解引用。

我们采用容易阅读的风格：

```c
int* p;
int** q;
```

但要注意：

```c
int* p, q;
```

这里 p 是指针，q 却是普通整数。因此最好每行只声明一个变量。

## 2. 修改指向 vs 修改数值

```c
int a = 10;
int b = 20;
int* p = &a;
```

### 修改指针的指向

```c
p = &b;
```

现在 p 指向 b。

但 a 仍然是 10，b 仍然是 20。

### 修改指向位置的值

```c
*p = 50;
```

因为 p 现在指向 b，所以 b 变成 50。

**核心区别：**

| 操作         | 改变的内容          |
| ------------ | ------------------- |
| `p = &b`     | p 保存的地址        |
| `*p = 50`    | p 指向的整数        |
| `int* q = p` | q 复制 p 保存的地址 |

## 3. Pointer Arithmetic — 指针运算

```c
int a[4] = {10, 20, 30, 40};
int* p = a;
```

在这里，数组名 a 在表达式中转换为第一个元素的地址。

```c
p       // 指向 a[0]
p + 1   // 指向 a[1]，但 p 不变
p++     // p 自身移动到下一个元素
*(p+2)  // 从 p 当前的位置向后两个元素，读取其值
```

指针加 1，移动的是一个**所指向对象类型**的大小。

例如 `int*` 每次跨越一个 `int`。

### 数组与指针的关系

```c
a[i] == *(a + i)
```

例如：

```c
a[2]       // 30
*(a + 2)   // 30
```

注意：数组名并不是一个能够随意修改的普通指针变量，所以不能写 `a++`。

## 4. Pointers and Functions — 指针与函数

**C 语言所有函数参数都是值传递。**

### 普通参数不能修改外部变量

```c
void change(int x) {
    x = 100;
}
```

调用 `change(a)` 时，x 只是 a 的值的一份副本。

### 指针参数可以修改外部变量

```c
void change(int* p) {
    *p = 100;
}
```

调用：

```c
change(&a);
```

函数收到 a 的地址，通过 `*p` 修改原来的 a。

### 使用指针交换两个变量

```c
void swap(int* x, int* y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}
```

调用：

```c
swap(&a, &b);
```

三个赋值步骤分别是：

1. 保存 a 原来的值。
2. 把 b 的值放入 a。
3. 把 a 原来的值放入 b。

**容易出错的地方：**

```c
int* temp = x;
x = y;
y = temp;
```

这只是交换函数内部指针保存的地址，不能交换外部整数的值。

## 5. Double Pointer — 二级指针

```c
int a = 10;
int* p = &a;
int** q = &p;
```

关系：

```text
q → p → a
```

| 表达式 | 含义                |
| ------ | ------------------- |
| `q`    | 保存 p 的地址       |
| `*q`   | 访问指针变量 p      |
| `**q`  | 访问 p 指向的整数 a |

例如：

```c
**q = 50;
```

最终 a 变成 50。

但：

```c
*q = &b;
```

修改的是 p 保存的地址，让 p 改为指向 b。

### 在函数中修改外部指针

```c
void redirect(int** pp, int* target) {
    *pp = target;
}
```

调用：

```c
redirect(&p, &b);
```

相当于通过 `pp` 修改 main 中真正的 p，让它指向 b。

**总结：**

- `*pp = target`：修改指针 p 的指向。
- `**pp = *target`：修改 p 指向的整数的值。

## 6. Pointers and Arrays — 指针与数组

### 6.1 使用指针遍历数组

```c
int a[4] = {10, 20, 30, 40};
int* p = a;

for (int i = 0; i < 4; i++) {
    printf("%d ", *(p + i));
}
```

输出：

```text
10 20 30 40
```

这里 `*(p+i)` 不会修改 p 的位置。

另一种方式：

```c
for (int i = 0; i < 4; i++) {
    printf("%d ", *p);
    p++;
}
```

这种方式会让 p 向后移动。

### 6.2 数组反转的基本思路

准备两个指针：

```c
int* start = a;
int* end = a + size - 1;
```

- start 指向开头。
- end 指向结尾。
- 交换 `*start` 和 `*end`。
- `start++`，`end--`。
- 重复直到两个指针相遇或交错。

## 7. Multidimensional Arrays — 二维数组

### 7.1 二维数组的结构

```c
int a[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};
```

它有 2 行，每行 3 个整数。

在内存中按行连续排列：

```text
a[0][0]  a[0][1]  a[0][2]  a[1][0]  a[1][1]  a[1][2]
   10       20       30       40       50       60
```

这叫 **Row-major Order（行优先存储）**。

所以 `a[0][2]` 后面紧接着就是 `a[1][0]`。

### 7.2 计算元素位置

对于每行有 3 个元素的数组：

```text
元素偏移量 = 行下标 × 3 + 列下标
```

例如 `a[1][1]`：

```text
1 × 3 + 1 = 4
```

从第一个整数开始，向后偏移 4 个整数，就是 50。

## 8. Pointer to Array — 数组指针

这是我们目前学习的重点。

```c
int (*q)[3] = a;
```

它的意思是：

**q 是一个指针，指向一个含有 3 个 int 的数组。**

在这个例子中，就是指向二维数组的一整行。

| 类型          | 指向的对象 | `+1` 移动的距离 |
| ------------- | ---------- | --------------- |
| `int* p`      | 一个整数   | 1 个 int        |
| `int (*q)[3]` | 一整行数组 | 3 个 int        |

例如：

```c
int (*q)[3] = a;
q++;
```

现在 q 指向第二行 `{40, 50, 60}`。

### 8.1 如何通过 q 访问元素？

```c
*q          // 第二行数组 a[1]
(*q)[0]     // 40
(*q)[1]     // 50
(*q)[2]     // 60
```

这里 `*q` 是一个数组表达式，在参与指针运算时会转换为指向这一行第一个整数的指针。

因此：

```c
*(*q + 1)   // 50
```

也可以写成：

```c
(*q)[1]     // 50
```

### 8.2 二维数组的双重解引用

对于二维数组 a：

```c
a[i][j] == *(*(a + i) + j)
```

理解步骤：

1. `a + i`：定位第 i 行。
2. `*(a+i)`：访问这一行数组。
3. `*(a+i)+j`：定位这一行的第 j 个整数。
4. `*(*(a+i)+j)`：访问最终的整数。

**特别注意：**

```c
int (*q)[3];   // 指向一个 int[3] 数组的指针
int* q[3];     // 包含三个 int* 元素的数组
int** q;       // 指向 int* 的二级指针
```

这三种类型不同，不能混为一谈。

二维数组虽然有两层下标，但它不是 `int**`。

## 9. 二维数组作为函数参数

对于：

```c
int table[2][3];
```

函数可以这样定义：

```c
void modify(int a[][3])
```

也可以写成：

```c
void modify(int (*a)[3])
```

这两种函数参数声明等价。

函数接收指向第一行的指针，可以直接修改原数组元素。

**为什么需要写列数 3？**

因为指针要知道一整行包含几个整数，才能正确执行 `a+1`。

### 9.1 我们最后完成的综合题

```c
void modify(int a[][3]) {
    a[0][0] = 100;
    a++;
    a[0][1] = 200;
}
```

原数组：

```c
int table[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};
```

执行 `modify(table)`：

- 第一句：把 `table[0][0]` 改为 100。
- `a++`：函数内部的指针移动到第二行。
- 此时 `a[0][1]` 对应原来的 `table[1][1]`。
- 最后把 `table[1][1]` 改为 200。

最终：

```c
{
    {100, 20, 30},
    {40, 200, 60}
}
```

输出：

```text
100 20 200
```

这里最关键的是：

**数组本身没移动，移动的是函数内部指向数组的指针。**

## 10. 最容易混淆的知识点总结

| 表达式        | 应该怎样理解                    |
| ------------- | ------------------------------- |
| `p`           | 指针保存的地址                  |
| `&p`          | 指针变量自身的地址              |
| `*p`          | p 指向的对象                    |
| `p++`         | 让 p 移动到下一个所指类型的对象 |
| `int** pp`    | 指向指针的指针                  |
| `*pp`         | pp 指向的指针变量               |
| `**pp`        | 再访问该指针指向的整数          |
| `int (*q)[3]` | 指向含三个整数的一整行的指针    |
| `q++`         | 当 q 为上述类型时，移动一整行   |
| `(*q)[1]`     | 当前指向行的第二个元素          |
| `a[i][j]`     | 第 i 行、第 j 列的元素          |

### 最重要的三个理解原则

**原则一：先看指针的类型，再决定 `+1` 跨越多远。**

**原则二：分清修改指针保存的地址，还是修改指针指向的值。**

**原则三：二维数组是数组的数组。先定位行，再定位元素。**
