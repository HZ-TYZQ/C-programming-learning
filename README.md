# C / C++ 合作学习项目

## 这是什么

这是 HZ-TYZQ 和 oxoxice 的合作学习仓库：HZ-TYZQ 学习 C，oxoxice 学习 C++，一起记录练习、整理笔记和交流问题。

## 这里有什么

主要收集平时的 C / C++ 练习、学习笔记和合作项目，慢慢积累喵。

| 目录 | 内容 |
| --- | --- |
| [TYZQ](TYZQ/) | HZ-TYZQ 的 C 语言练习和笔记 |
| [oxoxice](oxoxice/) | oxoxice 的 C++ 练习和笔记 |
| [Collaboration](Collaboration/) | 两人共同完成的练习和项目 |

Git 操作可以参考 [oxoxice 的 Git 上手练习](oxoxice/GitGuidance.md)。

## 代码约定

- C 源文件使用 `.c`，C++ 源文件使用 `.cpp`，分别使用对应的编译器，例如 GCC 的 `gcc` 和 `g++`。
- 每个合作项目在自己的 README 中注明使用的语言、编译和运行方法。
- 编译产物放在各自的 `build/` 或 `builds/` 目录中，这些目录已被 Git 忽略。

仓库名称暂时沿用 `C-programming-learning`，克隆地址不变。

可以帮我们检查学习进度、排查代码问题，也欢迎分享 C / C++ 小知识。
